# 欢聚 · Festival Games

为美国华人教会节日聚会设计的互动破冰游戏，支持简体、繁体与英文。无需账号、后端或构建步骤，一台连接投影的电脑即可使用。

## 包含的游戏

- **中秋 · 同心一轮月**：限时抽卡分享，从食物与家乡聊到感谢与信仰。
- **春节 · 恩典接福**：回望、感谢、祝福三步接力。
- **元宵 · 灯谜寻光**：关于光、道路与盼望的分组竞猜。
- **全年 · 家宴连线**：在人群中寻找共同点的 4×4 破冰宾果，点亮格子后可以写下那位朋友的名字。

页面不收集参与者资料，游戏状态只保留在当前浏览器会话中。

## 语言

界面提供**简 / 繁 / EN** 三种切换。繁体不是另一份文案：页面在渲染时把简体逐字转换成繁体，只有少数一简对多繁的词（灯台、农历、一只）在 `S2T_WORDS` 里单列。新增中文内容只需要写简体，繁体会自动跟上；若用到表里没有的简体字，把它补进 `S2T_PAIRS` 即可。

## 自检

```bash
./selftest.sh
```

用无头 Chrome 跑一遍四个游戏与玩法弹窗，确认切到繁体后页面上不再留下任何简体字。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## GitHub Pages

项目使用纯静态文件和相对路径，可以直接作为 `nullbotnone.github.io` 的 `/festival-games/` 子目录，也可以作为独立仓库通过 GitHub Pages 发布。

若作为独立仓库发布：

1. 将本目录推送到 GitHub 仓库。
2. 在仓库 **Settings → Pages** 中，将 Source 设为 **GitHub Actions**。
3. 推送到 `main` 后，随附的工作流会自动发布。

## 设计与内容

视觉系统延续 `slashai.app` 的深青黑、金色、宋体标题与控制台式界面。内容适合教会节日聚会，主持人提示强调节奏与倾听。

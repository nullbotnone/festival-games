# 欢聚 · Festival Games

为美国华人教会节日聚会设计的双语互动破冰游戏。无需账号、后端或构建步骤，一台连接投影的电脑即可使用。

## 包含的游戏

- **中秋 · 同心一轮月**：限时抽卡分享，从食物与家乡聊到感谢与信仰。
- **春节 · 恩典接福**：回望、感谢、祝福三步接力。
- **元宵 · 灯谜寻光**：关于光、道路与盼望的分组竞猜。
- **全年 · 家宴连线**：在人群中寻找共同点的 4×4 破冰宾果。

页面不收集参与者资料，游戏状态只保留在当前浏览器会话中。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## GitHub Pages

项目使用纯静态文件和相对路径，可以直接作为 `nullbotnone.github.io` 的 `/festival-games/` 子目录，也可以作为独立仓库通过 GitHub Pages 发布。

若作为独立仓库发布：

1. 将本目录推送到 GitHub 仓库。
2. 在仓库 **Settings → Pages** 中，将 Source 设为 **GitHub Actions**。
3. 推送到 `main` 后，随附的工作流会自动发布。

## 设计与内容

视觉系统延续 `slashai.app` 的深青黑、金色、宋体标题与控制台式界面。内容适合教会节日聚会，主持人提示强调节奏与倾听。
